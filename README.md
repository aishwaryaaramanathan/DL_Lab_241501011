# Deep Learning Experiments

### Experiment 1: Three-Layer Neural Network from Scratch
Implement a three-layer neural network using NumPy and backpropagation to classify handwritten digits from the MNIST dataset.

### Experiment 2: Multi-Layer Perceptron (MLP) for Classification
Build an MLP to classify Iris flower species and compare different hidden layer configurations and activation functions.

### Experiment 3: Comparison of SGD with Momentum vs Adam Optimizer
Compare SGD with momentum and Adam optimizers based on training loss, accuracy, and convergence using CIFAR-10.

### Experiment 4: Implementation of a Convolutional Neural Network (CNN)
Implement a CNN using PyTorch for CIFAR-10 image classification and visualize learned convolutional filters.

### Experiment 5: Comparative Analysis of VGG, ResNet, and GoogLeNet
Compare VGG16, ResNet18, and GoogLeNet using transfer learning for image classification.

### Experiment 6: BiRNN vs Feedforward Neural Network for Time-Series Prediction
Predict airline passenger numbers using a Bidirectional RNN and a Feedforward Neural Network and compare their performance using MSE.

### Experiment 7: Image Captioning Using CNN-RNN Architecture
Generate natural-language captions for images using a pretrained ViT-GPT-2 encoder-decoder model.

### Experiment 8: Image Generation Using Variational Autoencoder (VAE)
Implement a VAE to learn latent representations of facial images and generate synthetic images.

### Experiment 9: Text Generation Using LSTM Networks
Train a character-level LSTM on the Shakespeare corpus to generate text from a given seed prompt.

### Experiment 10: Image Generation Using Generative Adversarial Network (GAN)
Generate synthetic images using a pretrained StyleGAN2-ADA model and explore image quality evaluation.
